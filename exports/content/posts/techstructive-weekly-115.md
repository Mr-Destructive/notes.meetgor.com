<ul><li>
<p><a href="https://pydantic.dev/docs/validation/2.9/concepts/validators/#before-after-wrap-and-plain-validators">Pydantic model before validator</a></p>
<ul>
<li><p>The before validator(@model_validator(mode=”before”)) receives the raw input data before Pydantic validates the model fields, so you can transform a string or dictionary into the structure your model expects.</p></li>
<li>
<p>This is cool because I wanted to do something like this <code>"text___key:value::key2:value2"</code></p>
<p>and convert to a python data</p>
<pre><code><code>{
    "text": "text",
    "key": "value",
    "key2": "value2",
}</code></code></pre>
